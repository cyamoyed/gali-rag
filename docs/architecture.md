# Gali-RAG 系统架构设计文档

## 一、系统整体分层架构

```
┌─────────────────────────────────────────────────────────────────┐
│                      接口路由层 (API Layer)                       │
│  FastAPI Router · 请求校验 · 异常处理 · 流式响应 · API Key认证      │
├─────────────────────────────────────────────────────────────────┤
│                     业务服务层 (Service Layer)                    │
│  知识库服务 · 文档服务 · 会话服务 · Prompt服务 · 系统配置服务        │
│  模型服务 · 目录层级服务 · 智能体服务                              │
├─────────────────────────────────────────────────────────────────┤
│                   RAG核心逻辑层 (RAG Core Layer)                  │
│  Query改写 · 多路召回(稠密+BM25) · 重排序 · 冲突检测 · RAG Pipeline│
├─────────────────────────────────────────────────────────────────┤
│                   存储持久层 (Storage Layer)                      │
│  SQLAlchemy/SQLite · Chroma向量库 · 文件系统                      │
├─────────────────────────────────────────────────────────────────┤
│                     工具层 (Utils Layer)                         │
│  文档解析器 · 文本切片器 · Token计数器 · LLM客户端 · 网页抓取器     │
└─────────────────────────────────────────────────────────────────┘
```

## 二、分层职责说明

### 2.1 接口路由层 (app/api/)
- **职责**：定义RESTful API端点，处理HTTP请求/响应，API Key认证
- **组件**：
  - `chat.py`：知识库管理、文档管理、目录层级管理接口
  - `agents.py`：智能体CRUD、发布/下线、智能体对话（流式/非流式）
  - `models.py`：AI模型CRUD、设为默认、测试连接
  - `prompts.py`：Prompt模板CRUD接口
  - `conversations.py`：会话与消息管理、导出接口
  - `system.py`：系统资源查询接口
- **特性**：Pydantic入参校验、统一错误格式、流式SSE响应、双模式认证（主Key + Agent Key）

### 2.2 业务服务层 (app/services/)
- **职责**：封装业务逻辑，协调多个底层组件
- **组件**：
  - `kb_service.py`：知识库CRUD，Chroma Collection管理
  - `doc_service.py`：文档上传、解析、切片、向量化全流程，网页抓取
  - `conv_service.py`：会话与消息记录管理
  - `prompt_service.py`：Prompt模板管理，内置默认模板
  - `system_service.py`：系统资源查询（向量库大小、数据库大小、文档数等）
  - `model_service.py`：AI模型CRUD，默认模型管理，连接测试
  - `category_service.py`：目录层级CRUD，树形结构管理
  - `agent_service.py`：智能体CRUD，发布/下线，API Key管理

### 2.3 RAG核心逻辑层 (app/rag/)
- **职责**：实现完整RAG检索增强生成链路
- **组件**：
  - `query_rewriter.py`：Query检索改写（利用对话历史补全指代）
  - `multi_retriever.py`：多路召回（稠密向量 + BM25关键词）
  - `reranker.py`：结果重排序与阈值过滤
  - `conflict_detector.py`：检索片段冲突检测
  - `pipeline.py`：RAG Pipeline全流程编排
  - `vector_store.py`：Chroma向量库操作封装
  - `bm25_retriever.py`：BM25检索实现
  - `llm_client.py`：LLM调用客户端（Ollama/OpenAI双模式，支持流式/非流式）

### 2.4 存储持久层
- **SQLite**：通过SQLAlchemy ORM管理，存储知识库、文档、智能体、会话、Prompt、模型、系统配置
- **Chroma**：本地持久化向量库，每个知识库独立Collection，支持HNSW索引参数配置
- **文件系统**：上传文件存储、导出文件存储

### 2.5 工具层 (app/utils/)
- `document_parser.py`：PDF/DOCX/MD/TXT文档解析
- `text_splitter.py`：固定长度切片 + 语义切片（Markdown标题切分）
- `token_counter.py`：Token计数与上下文截断

## 三、RAG问答完整链路流程

```
用户Query
    │
    ▼
┌──────────────┐
│ 1.Query改写  │ ← 利用对话历史补全指代，优化检索效果
└──────┬───────┘
       │
       ▼
┌──────────────────────────────┐
│ 2.多路召回                     │
│ ┌────────────┐ ┌───────────┐ │
│ │ 稠密向量检索 │ │ BM25检索   │ │
│ │ (Chroma)   │ │ (jieba)   │ │
│ └─────┬──────┘ └─────┬─────┘ │
│       └──────┬───────┘       │
│              ▼               │
│        合并去重               │
└──────────────┬───────────────┘
               │
               ▼
┌──────────────┐
│ 3.重排序过滤  │ ← 加权融合得分，阈值过滤低质量片段
└──────┬───────┘
       │
       ▼
┌──────────────┐
│ 4.无匹配检测  │ ← 所有片段低于阈值 → 返回固定话术，不调用LLM
└──────┬───────┘
       │ (有匹配)
       ▼
┌──────────────┐
│ 5.冲突检测   │ ← LLM判断片段间是否存在事实矛盾
└──────┬───────┘
       │
       ▼
┌──────────────┐
│ 6.Prompt拼接 │ ← 读取自定义模板，填充检索片段、引用来源、冲突信息
└──────┬───────┘
       │
       ▼
┌──────────────┐
│ 7.LLM生成    │ ← 流式/非流式调用，严格限定基于片段回答
└──────┬───────┘
       │
       ▼
┌──────────────┐
│ 8.结果返回   │ ← 回答 + 引用溯源 + 冲突信息 + 耗时
└──────────────┘
```

## 四、智能体对话流程

```
用户Query → 智能体对话接口
    │
    ▼
┌──────────────┐
│ 验证智能体配置 │ ← 必须配置对话模型和关联知识库
└──────┬───────┘
       │
       ▼
┌──────────────────────────────┐
│ 多知识库联合检索                │
│ 遍历agent关联的所有知识库       │
│ 每个库独立召回→重排序→合并       │
│ 全局去重后取TopK               │
└──────────────┬───────────────┘
               │
               ▼
┌──────────────┐
│ 使用Agent配置 │ ← system_prompt + temperature + max_tokens
│ 拼接Prompt   │
└──────┬───────┘
       │
       ▼
┌──────────────┐
│ Agent专用LLM  │ ← 可独立于系统默认LLM
│ 生成回答      │
└──────┬───────┘
       │
       ▼
┌──────────────┐
│ 流式/非流式   │ ← SSE流式返回 token/sources/conflict/latency/end
│ 结果返回      │
└──────────────┘
```

## 五、数据流向

```
上传文档 → 文件系统存储 → 文档解析 → 文本清洗 → 智能切片 → Chroma向量入库
                                                                        │
智能体对话 → Query改写 → 多路召回(向量+BM25) → 重排序 → Prompt拼接 → LLM生成 ←──┘
                                                                        │
                                              会话记录 ← SQLite ←──────┘
```

## 六、认证架构

```
请求 → auth_and_log_middleware
    │
    ├─ 公开路径(/health, /docs等) → 直接放行
    │
    ├─ X-API-Key == 主Key → 系统管理权限
    │
    ├─ X-API-Key starts with "agent_" → 查询agents表匹配
    │   ├─ 匹配且published → 智能体权限
    │   └─ 不匹配 → 401
    │
    └─ 无Key或不匹配 → 401
```

## 七、前端功能模块层级

### 7.1 一级模块（独立页面/功能区）

```
知识库管理 ─┬─ 目录层级
            ├─ 文档管理
            ├─ 切片配置
            ├─ 向量管理
            ├─ 网页抓取
            └─ 命中测试

智能体管理 ─┬─ 关联知识库（多对多）
            ├─ 关联模型（LLM）
            └─ 对话功能（内部走 RAG Pipeline）

模型管理    （独立，被知识库和智能体引用）
Prompt 模板  （独立，被问答对话引用）
会话管理    （独立，记录对话历史）
系统配置    （独立，仅资源查询）
```

### 7.2 各模块功能清单

#### 7.2.1 知识库管理
| 子功能 | 说明 |
|--------|------|
| 知识库 CRUD | 创建/编辑/删除/列表，支持 general 和 web 两种类型 |
| 目录层级 | 树形目录管理，用于组织知识库（删除目录后知识库移至未分类） |
| 文档管理 | 上传/删除/重新处理/摘要生成，支持 PDF/DOCX/MD/TXT |
| 切片配置 | chunk_size、chunk_overlap、语义切片、LLM辅助切片开关 |
| 向量管理 | 清理失效向量、清空知识库向量 |
| 网页抓取 | web 类型知识库的 URL 配置和抓取 |
| 命中测试 | 仅检索不调用 LLM，用于验证检索效果 |

#### 7.2.2 智能体管理
| 子功能 | 说明 |
|--------|------|
| 智能体 CRUD | 创建/编辑/删除/列表，配置 system_prompt/temperature/模型/知识库 |
| 发布/下线 | 控制智能体可用状态 |
| API Key 管理 | 发布时自动生成，支持重新生成 |
| 智能体对话 | 流式 SSE/非流式，自动关联多知识库联合检索 |

#### 7.2.3 模型管理
| 子功能 | 说明 |
|--------|------|
| 模型 CRUD | 支持 LLM/Embedding/Reranking/Speech/Vision 五种类型 |
| 设为默认 | 每种类型可设一个默认模型 |
| 测试连接 | 验证模型配置是否可用 |

#### 7.2.4 Prompt 模板管理
| 子功能 | 说明 |
|--------|------|
| Prompt CRUD | 自定义提示词模板，按 category 分类 |
| 重置/设为默认 | 系统内置模板不可删除，可重置为默认 |

#### 7.2.5 会话管理
| 子功能 | 说明 |
|--------|------|
| 会话列表 | 按智能体筛选 |
| 消息查询 | 查看会话内所有消息 |
| 导出 | 单会话导出 / 全部问答日志导出 |

#### 7.2.6 系统配置
| 子功能 | 说明 |
|--------|------|
| 系统资源查询 | 向量库大小、数据库大小、上传文件大小、文档数、切片数 |

### 7.3 内部流程（非独立模块）

RAG Pipeline 是问答对话的内部实现链路，体现在知识库命中测试和智能体对话中，不是前端独立页面：

```
Query改写 → 多路召回(稠密+BM25) → 重排序 → 无匹配检测 → 冲突检测 → Prompt拼接 → LLM生成
```
